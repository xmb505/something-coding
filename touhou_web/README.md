# 三一 SANY Project · 网页版游戏界面

一套**单页游戏界面**（东方风 STG 外壳 + 工业车间皮肤）：

- 整个画面是一个 **4:3 的游戏框**（和原作 640×480 窗口一个比例），框里左边是**游戏区**、右边是 HUD
- 游戏区放你自己的「焊接打火花」视频，上面站着**灵梦**（红魔乡自机图集，会走路、能拖着走、按 Z 连射）
- 背景是车间底板：钢板拼缝 + 细格 + 红绿电路走线 + 螺栓（异星工厂那味儿）
- HUD：Hi-Score / Score / 剩余人数 / Spell Card / 灵力 / **学分** / 电压 / Graze，数字会自己动
- 4 个演出效果按钮：**自爆 / STAGE / 符卡 / 弹幕**

## 打开

```bash
cd ~/touhou_web
python3 -m http.server 8765        # 然后浏览器打开 http://127.0.0.1:8765/
```

直接双击 `index.html` 也能用（`file://`），只是「自动加载 assets/spark.mp4」在部分浏览器里会被拦。

## 演出效果（按钮 + 数字键）

| 按钮 | 键 | 效果 |
|---|---|---|
| **自爆** | `1` / `X` | 灵梦原地爆炸，照 Taisei 的 `player_death` 实现：① **整块游戏区反色 1.5 秒**（原作 shader 的 90 帧），画面只是变负片、内容还看得见 ② 5 条圆弧从死亡点旋转着扩到全屏 ③ 扩散的薄雾 + 彩色噪点 ④ 60 颗 flare 往外飞并缩到没有 ⑤ 深红冲击波 0→3.4 倍 ⑥ 橙色大光环从 5 倍往里缩 ⑦ 自机被**拉成竖条**消失，然后周围炸一圈小爆 ⑧ 掉 6 个 P 点 ⑨ 掉命，自机**从画面下方飞回来**（60 帧）⑩ 起身后无敌闪烁 3.5 秒 |
| **STAGE** | `2` / `T` | 再放一次中间那行「Stage 2.5 / 毕业之前的毕设焊接遭遇战」，顺便把 BGM 条也放一遍 |
| **符卡** | `3` / `C` | 符卡宣言演出：画面压暗、灵梦立绘从右边斜切飞入、左边滑出符卡名横幅、右上角 50→0 倒计时 + 旋转符阵圈。符卡名是工业风的，见 `js/main.js` 里的 `SPELL_NAMES`：`工符「MASTER FIRE SPARK」`、`焊符「二氧化碳保护焊」`、`切符「氧乙炔气体切割」`、`熔符「氩弧焊·TIG」`… |
| **弹幕** | `4` / `B` | 红色 **WARNING!** 闪烁横幅，然后子弹（红球/金球/紫米弹/青星弹/橙晶弹/「泰西」御札）从上方成片落下，期间 Graze 疯涨 |

> 自爆那几个常数都对着 Taisei 源码抄的：反色覆盖层 90 帧、deathbomb 窗口 12 帧、复活 60 帧、无敌 210 帧（`src/player.c` / `src/plrmodes/reimu.c`）。

## Z 键连射 + 捡东西

按住 `Z` 一直打（灵梦的御札，两发一排），同时画面上方会随机掉两种东西：

| 掉下来的 | 是什么 | 收到会怎样 |
|---|---|---|
| `assets/power.png` | P 点（红） | **灵力 +0.05**，HUD 上 `1.00 / 4.00` 实时涨 |
| `assets/credit.png` | 学分（蓝「分」） | **学分 +100**，HUD 上 `010,000` 实时涨 |

掉到自机 15% 宽度范围内会被**吸过去**，越近吸得越快，吃到弹一个小火花。没吸到的就掉出画面消失。

## 换视频

三种方式：

1. **拖进去** —— 视频文件直接拖到游戏区
2. **点按钮** —— 控制条上的「导入视频」
3. **固定用同一个** —— 命名成 `assets/spark.mp4` 丢进去，打开页面自动加载

视频不会上传，只在本机用 `blob:` 播。

### 拉伸 / 裁剪

游戏区是竖的 384:448 窗口，超出的部分裁掉：

| 操作 | 说明 |
|---|---|
| **铺满 / 适应 / 拉伸** | 循环切换：裁掉四周填满 / 完整显示留黑边 / 硬拉变形 |
| **宽 / 高** | 独立缩放 20%~400% |
| **左右 / 上下** | 平移画面 = 选裁剪范围 |
| 滚轮 | 在游戏区上滚 = 整体缩放 |
| 拖动 | 在游戏区上按住拖 = 平移 |

> 铺满模式下视频高度正好等于游戏区高度，**上下是没有多余画面可移的**：先滚轮放大（或把「宽/高」调大）就能上下拖了。硬要拖的时候会弹提示告诉你。

控制条闲置 4 秒自动收，鼠标移进游戏区就出来。

| 键 | 作用 |
|---|---|
| `H` | 控制条常驻 / 自动隐藏 |

## 文件结构

```
touhou_web/
├── index.html          # 结构，改文字直接改这里
├── css/style.css       # 所有样式（4:3 框、工业底纹、配色、特效动画）
├── js/main.js          # 视频、灵梦、连射掉道具、HUD 动画、四个演出效果
└── assets/
    ├── reimu-walk.png      # 灵梦 4 帧行走图集（32×48 × 4）
    ├── reimu-cutin.png     # 符卡立绘
    ├── player0.png         # 灵梦原始图集（想自己切帧用）
    ├── orb.png             # 阴阳玉
    ├── bullet-*.png        # 弹幕子弹（ball/bigball/rice/star/crystal/ofuda）
    ├── fx-blast.png        # 冲击波
    ├── fx-flare.png        # 核心光 / flare
    ├── heart.png / heart_empty.png   # 剩余人数
    ├── star.png  / star_empty.png    # Spell Card
    ├── credit.png / power.png        # 学分 / 灵力图标
    ├── sanyi.svg           # 三一 logo（官方标志，裁掉了字标）
    └── pattern.svg         # 车间底板纹样（钢板拼缝 + 电路走线 + 螺栓）
```

想改分数、关卡名、BGM 名、符卡名（`SPELL_NAMES`）：`index.html` / `js/main.js` 里搜那行字。
想改配色：`css/style.css` 里的 `.c-power / .c-point / .c-voltage / .c-graze`。
想让游戏框更大/更小：`.frame` 的 `height: min(94vh, 70.5vw)`。
